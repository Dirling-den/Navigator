GraphNavigator

Высокопроизводительный навигатор по паркам Москвы на C++ с использованием алгоритма А*, Дейкстра, Ближайшего соседа.

Открыть код на SourceCraft

О проекте

Проект представляет собой автономное высокопроизводительное настольное приложение (.exe) для интерактивной навигации по сложным пешеходным зонам и паркам Москвы (Ботанический сад МГУ, ВДНХ, Сокольники). Карта динамически генерируется на основе реальных географических данных OpenStreetMap.

Архитектура и Стек

Ядро на C++

Использование ООП архитектуры, разделение на модули (.hpp/.cpp) и контейнеров STL для максимального быстродействия поиска.

OpenStreetMap

Самостоятельный построчный парсинг XML-данных формата .osm, извлечение тегов дорог и расчет расстояний по формуле гаверсинусов.

Алгоритм А*

Поиск кратчайшего пути с использованием очереди с приоритетами (Мин-куча) и кастомной евклидовой эвристики.

Алгоритм Дейкстры

Поиск ближайших объектов инфраструктуры парка (кафе, выходов к метро) из текущей точки с использованием Multi-source подхода.

Ближайший сосед (TSP)

Жадный алгоритм для автоматического построения сквозного экскурсионного маршрута по выбранным достопримечательностям.

Сайт-презентация

Интерактивный веб-постер (Landing Page) на HTML и CSS для защиты проекта, демонстрирующий архитектуру кода, стек и результаты экспериментов.
